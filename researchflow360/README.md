# Research Flow 360 — researchflow360.com

Standalone site for Research Flow 360 (Accel Financial Solutions). Generated by `python3 src/build.py`
from `src/research.body.html`; don't edit `index.html` here by hand.

## Put it on researchflow360.com

Any static host works. Two easy options:

**A. Its own GitHub repository with GitHub Pages**
1. Create a repository (for example `researchflow360-site`) and copy this folder's contents into its root.
2. Settings → Pages → deploy from the `main` branch, root folder. The `CNAME` file already says `researchflow360.com`.
3. At your domain registrar, add DNS records:
   - `A` records for `researchflow360.com` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` record for `www` → `<your-github-username>.github.io`
4. Back in Settings → Pages, tick "Enforce HTTPS" once the certificate is issued.

**B. Cloudflare Pages or Netlify**
Point a new project at this folder (no build command), then add `researchflow360.com` as a custom
domain and follow the DNS steps the host shows.
